## My Documentation Approach

Good documentation is not about describing features — it is about helping users achieve their goals.

My approach combines:

<div class="grid cards" markdown>

-   :material-account-group: **User-Centered Writing**

    ---

    I analyze user goals, workflows, and pain points to create documentation that helps users complete tasks efficiently.

-   :material-file-tree: **Structured Content**

    ---

    I create reusable content models using DITA principles, topic-based authoring, and consistent information architecture.

-   :material-code-braces: **Docs as Code**

    ---

-   :material-shield-check: **Domain Expertise**

    Experience documenting cybersecurity, fintech, enterprise software, and complex technical products.
