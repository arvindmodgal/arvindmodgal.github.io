# Documentation Approach

## User-centered information architecture

The documentation was structured around user goals rather than product features.

Users can quickly find information based on what they want to accomplish:

- Manage devices
- Upload firmware
- Run assessments
- Review results
- Resolve issues

---

## Task-based writing

Procedures focus on completing user tasks.

Each procedure answers:

- What can the user accomplish?
- When should they perform this task?
- What steps are required?
- What is the expected outcome?

---

## Content organization

The documentation follows a topic-based structure:

- Concepts explain important product information
- Tasks describe user workflows
- References provide supporting details
