# Jira integration

FirmwareCheck can be connected to Jira so you can create and access tickets directly from the application.

## Configure Jira connection

**To connect FirmwareCheck with Jira:**

1. On the left-hand panel, click **Integrations**.
2. Under **Jira**, click **Connect**.
3. On the **Configure Jira connection** page, enter:
      - Jira server or cloud URL
      - Username
      - API token
4. Click **Save**.
