# Manage devices

Create and manage device records before uploading firmware and running assessments.

## At a glance

In this section, you'll learn how to:

- Create a device.
- Find a device.
- Update device information.
- Archive a device.
- Delete a device.

Device records help you organize firmware versions, assessment results, and compliance information throughout the product lifecycle.

## Before you begin

- Sign in to FirmwareCheck.
- Ensure that you have permission to create and manage devices.
