# Connect Jira

Connect FirmwareCheck to your Jira instance so assessment findings can be converted into Jira issues.

## Before you begin

- Obtain the Jira URL.
- Obtain the required authentication credentials.
- Ensure you have permission to create issues in the target Jira project.

1. In the navigation pane, click **Integrations**.

2. Select **Jira**.

3. Click **Add integration**.

4. Enter the required information:

    - Jira URL
    - Project
    - Username or email
    - API token

5. Click **Test connection**.

6. Click **Save**.

FirmwareCheck validates the connection and stores the integration settings.

!!! tip

    Test the connection before saving the configuration to verify that the supplied credentials are correct.
