# Jira integration

Connect FirmwareCheck to Jira so security findings can be tracked and managed as part of your existing development workflow.

After the integration is configured, you can create Jira issues directly from assessment findings without leaving FirmwareCheck.

## At a glance

In this section, you'll learn how to:

- Connect FirmwareCheck to a Jira instance.
- Create Jira issues from assessment findings.
- Track remediation activities in Jira.

## Typical workflow

To use the Jira integration, complete the following tasks in order:

1. Connect FirmwareCheck to Jira.
2. Open an assessment result.
3. Create a Jira issue for the selected finding.
