# Create a Jira issue

Create a Jira issue from an assessment finding to track remediation work within your development process.

## Before you begin

- Configure the Jira integration.
- Open a completed assessment.

## To creat a Jira issue:

1. Open the assessment results.

2. Select the finding you want to track.

3. Click **Create Jira issue**.

4. Verify the issue details.

5. Select the Jira project.

6. Click **Create**.

FirmwareCheck creates the issue and displays the Jira issue key.

!!! note

    The created issue includes the assessment details required to investigate the finding.

## Next steps

Continue working with the issue in Jira according to your organization's remediation process.
