# What is firmware?

A **firmware image** is the software package that runs on a device. FirmwareCheck analyzes the uploaded firmware image to identify software components, known vulnerabilities, potential zero-day vulnerabilities, and compliance issues.

Unlike a device record, which stores information about the physical product, a firmware image contains the software that is assessed.

A device can have one or more firmware images associated with it, allowing you to assess different firmware versions throughout the product lifecycle.

## Firmware image information

A firmware image typically includes:

- Firmware version
- File name
- File size
- Upload date
- Assessment status

After you upload a firmware image, you can run one or more assessments against it.

!!! note

    Uploading a firmware image does not automatically start an assessment. You must explicitly run an assessment after the upload is complete.
