# Replace firmware

Replace an existing firmware image when a newer firmware version becomes available or when you want to reassess a device using updated firmware.

## Before you begin

- Sign in to FirmwareCheck.
- Locate the device that contains the firmware you want to replace.

## To replace a firmware:
1. In the navigation pane, click **FirmwareCheck**.

2. Open the device.

3. Select the existing firmware.

4. Click **Replace firmware**.

5. Browse to and select the new firmware image.

6. Verify that you selected the correct firmware version.

7. Click **Upload**.

The new firmware image replaces the previous version and is available for assessment.

!!! tip

    Record firmware version numbers consistently so you can compare assessment results across releases.
