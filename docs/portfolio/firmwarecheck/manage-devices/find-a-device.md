# Find a device
Locate an existing device by browsing or filtering the device list.

## Before you begin

- Sign in to FirmwareCheck.
- At least one device exists in your workspace.

## To find or view a Device:
1. In the navigation pane, click **FirmwareCheck**.

2. Open the **Devices** page.

3. Use one or more of the following options to locate a device:

    - Enter a device name in the **Search** box.
    - Filter devices by **Active**, **Archived**, or **Deleted** status.
    - Sort the list by name or last modified date (if available).

4. Select the device from the list.

The device details page opens.

!!! tip

    Use the search box together with status filters to quickly locate a device in workspaces containing many products.
