# Manage devices

A device represents the physical product you want to assess in FirmwareCheck. Before you can upload firmware or run an assessment, you must create a device record.

This section explains how to create, manage, and organize device records throughout their lifecycle.

## At a glance

In this section, you'll learn how to:

- Understand what a device represents.
- Understand device statuses.
- Create and manage device records.
- Find existing devices.
- Archive or delete devices when they are no longer required.

## Typical workflow

To assess firmware in FirmwareCheck, complete the following tasks in order:

1. [Create a device](create-a-device.md)
2. [Add firmware to a device](../manage-firmware/upload-firmware.md)
3. [Run an assessment](../assessments/create-an-assessment.md)
