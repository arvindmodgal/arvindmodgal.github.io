# Frequently asked questions

This section answers common questions about using FirmwareCheck.

## Why can't I upload firmware before creating a device?

FirmwareCheck associates every firmware image with a device record. Create the device first, and then upload the firmware.

For more information, see [Create a device](manage-devices/create-a-device.md).

---

## Does uploading firmware automatically start an assessment?

No. Uploading firmware only stores the firmware image. You must manually run an assessment.

For more information, see [Run an assessment](run-assessments/run-an-assessment.md).

---

## Can I run more than one assessment on the same firmware?

Yes. A firmware image can be assessed multiple times using different assessment types.

For more information, see [Assessment types](run-assessments/assessment-types.md).

---

## What's the difference between a device and firmware?

A device represents the physical product.

Firmware is the software that runs on the device. Each device can have one or more associated firmware images.

For more information, see [What is a device?](manage-devices/what-is-a-device.md) and [What is firmware?](manage-firmware/what-is-firmware.md).

---

## Can I replace firmware after uploading it?

Yes. Replace the existing firmware image when a newer firmware version becomes available.

For more information, see [Replace firmware](manage-firmware/replace-firmware.md).

---

## Can I recover a deleted device?

No. Deleting a device permanently removes it from FirmwareCheck.

If you might need the device again, archive it instead of deleting it.

For more information, see [Archive a device](manage-devices/archive-a-device.md).

---

## How long does an assessment take?

Assessment time depends on factors such as firmware size, assessment type, and system workload.

You can monitor progress from the assessment page.

---

## Can I create Jira issues directly from assessment results?

Yes. After configuring the Jira integration, you can create Jira issues without leaving FirmwareCheck.

For more information, see [Jira integration](jira-integration.md).

---

## Where can I find the Software Bill of Materials (SBOM)?

The SBOM is available as part of the assessment results after an assessment completes.

For more information, see [View assessment results](run-assessments/view-assessment-results.md).

---

## Where can I get additional help?

If you can't resolve an issue using this guide, contact your FirmwareCheck administrator or your organization's support team.
