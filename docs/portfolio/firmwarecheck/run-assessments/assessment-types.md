# Assessment types

FirmwareCheck provides multiple assessment types to help you identify security risks and compliance issues in firmware. Each assessment focuses on a different aspect of firmware security.

Choose the assessment that best matches your security or compliance objective.

## Vulnerability assessment

A vulnerability assessment identifies publicly disclosed vulnerabilities (CVEs) affecting software components contained in the firmware.

Use this assessment to:

- Identify known security vulnerabilities.
- Review affected software packages.
- Prioritize remediation activities based on severity.

---

## Policy assessment

A policy assessment evaluates firmware against selected security policies and industry standards.

Use this assessment to:

- Verify compliance with organizational security policies.
- Check adherence to industry standards.
- Identify policy violations before product release.

---

## Zero-day assessment

A zero-day assessment uses advanced analysis techniques to identify potential vulnerabilities that are not yet publicly disclosed.

Use this assessment to:

- Detect previously unknown security weaknesses.
- Evaluate products requiring a higher level of security assurance.
- Supplement vulnerability assessments with deeper analysis.

!!! note

    Each assessment provides different information. Running multiple assessment types gives a more complete view of the firmware's security posture.
