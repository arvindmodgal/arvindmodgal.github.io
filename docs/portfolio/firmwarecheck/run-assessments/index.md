# Run assessments

After uploading firmware, run an assessment to identify vulnerabilities, security risks, and compliance issues.

FirmwareCheck supports multiple assessment types, allowing you to analyze firmware from different security perspectives.

## At a glance

In this section, you'll learn how to:

- Understand the available assessment types.
- Run an assessment against a firmware image.
- Review assessment results.
- Use assessment findings to improve product security.

## Typical workflow

Complete the following tasks in order:

1. [Upload firmware](../manage-firmware/upload-firmware.md)
2. [Run an assessment](run-an-assessment.md)
3. [View assessment results](view-assessment-results.md)
